---
name: design-system-contract
description: Create or refine project design tokens and enforce the approved version across mockups, implementation and review.
---

Pull `get_design_system` for the assignment's frozen revision. Start with audience, interface density, constraints and existing project conventions. Use role-based colors, a small spacing scale, typography roles and component states. Check text and action contrast before proposing tokens. Use tokens rather than scattered literal colors. Include empty, loading, error, disabled and focus states.

Propose exceptions as human decisions; do not silently change an approved contract. Include its version/hash in the handoff with actual screenshots, viewports and check results. One Connect exposes DESIGN.md and CSS token exports; generate mocks as local artifacts in the assignment's allowed paths.
