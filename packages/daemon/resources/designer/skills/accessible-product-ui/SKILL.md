---
name: accessible-product-ui
description: Design and review keyboard, screen-reader, contrast and reduced-motion behavior in product interfaces.
---

Use semantic controls and accessible names. Label fields visibly; connect errors to fields and announce asynchronous results. Keep keyboard focus visible and unobscured, return focus after dialogs, and provide a logical tab order. Status needs text or icons as well as color. Verify text contrast and target sizes; test the interface at 200% zoom. Respect reduced motion. Report actual keyboard and screen-reader checks separately from static contrast checks; neither alone proves accessibility.
