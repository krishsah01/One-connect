# one-connect site

Static, dependency-free landing page built on the design system. `tokens.css` is a copy of
`packages/web/src/tokens.css` (regenerate with `node scripts/design-tokens.mjs` and copy). Open `index.html` directly, or
serve the folder from any static host. `assets/shot-*.png` are screenshots of the offline demo in night mode.

To bring it into Figma: open the page in a browser and use the html.to.design plugin, or import the published artifact link.
