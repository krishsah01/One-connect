# Code of Conduct

This project adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its code of conduct. Its full text is incorporated here by reference.

In short, we pledge to make participation a harassment-free experience for everyone, and to:

- be respectful of differing viewpoints and experiences;
- give and gracefully accept constructive feedback;
- focus on what is best for the community;
- not tolerate harassment, insults, sexualized language or imagery, doxxing, or other conduct that would be inappropriate in a professional setting.

The Covenant applies in all project spaces, and when someone officially represents the project in public spaces.
